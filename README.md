# Análise de Vendas de E-commerce - Power BI

<a href="https://app.powerbi.com/groups/me/reports/96a6c780-024a-4add-b6ef-c9df24b8d602/4534026ce6bbd79b9d9e?experience=power-bi" target="_blank" rel="noopener noreferrer">Meu Projeto no PowerBI</a><br><br>
Projeto completo de análise de dados de vendas de e-commerce utilizando Power BI, com dados fictícios simulando um ambiente real de negócios.

## 📌 Objetivo
Analisar o desempenho de vendas, identificar padrões de compra, segmentar clientes e produtos para auxiliar na tomada de decisões estratégicas.

## 📊 Fontes de Dados
- `vendas.xlsx`: Registros de transações de vendas
- `clientes.xlsx`: Dados demográficos dos clientes
- `produtos.xlsx`: Catálogo de produtos com informações de custo e preço

## 🛠️ Ferramentas Utilizadas
- Power BI Desktop para ETL e visualização
- DAX para cálculos avançados
- Power Query para transformação de dados

## 📈 Principais Métricas
- Vendas totais
- Quantidade vendida
- Lucro e margem de lucro
- Vendas YTD (Year-to-Date)
- Análise por segmento (produto, cliente, região)

## 🔍 Insights Principais
1. Produtos da categoria "Eletrônicos" representam 45% do total de vendas
2. Clientes do sexo feminino têm ticket médio 15% superior
3. A região Sudeste responde por 60% do volume de vendas
4. Pagamentos via PIX têm crescimento de 25% trimestral

## 🚀 Como Utilizar
1. Clone este repositório
2. Abra o arquivo `Analise_Ecommerce.pbix` no Power BI Desktop
3. Explore as diferentes páginas do dashboard
4. Utilize os filtros interativos para análises específicas
